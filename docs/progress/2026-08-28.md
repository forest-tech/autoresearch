  - 改善してたら採用、悪化してたら棄却のシステムができてなかった

## 実験フロー

```text
人間
 │
 │ あらかじめ autoresearch/* ブランチを作る
 ▼
loop_for.sh
 │
 ├─ ① baseline train.py を実行
 │      ↓
 │    train.log
 │      ↓
 │    シェルが val_bpb を抽出
 │      ↓
 │    results.tsv に記録
 │
 ├─ ② Codex
 │      ├─ results.jsonl を読む
 │      ├─ 過去のログ・diffを見る
 │      └─ train.py だけ変更
 │
 ├─ ③ シェルが変更diffを保存
 │
 ├─ ④ train.py を実行
 │
 ├─ ⑤ シェルが結果を解析
 │
 ├─ 改善 → keep + git commit
 │
 └─ 悪化 → discard + train.py を元に戻す
        │
        └────────────→ 次のCodex
```
