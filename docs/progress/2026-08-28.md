```text
人間

 │    train.log
 │      ↓

 │    results.tsv に記録
 │
 ├─ ② Codex
 │      ├─ results.jsonl を読む

 │
 ├─ ③ シェルが変更diffを保存
 │

 │
 ├─ ⑤ シェルが結果を解析
 │
 ├─ 改善 → keep + git commit
 │
 └─ 悪化 → discard + train.py を元に戻す
        │
        └────────────→ 次のCodex
```
