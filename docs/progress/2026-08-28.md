## 実験フロー

```text
人間
 │
 │ あらかじめ autoresearch/* ブランチを作る
 ▼
loop_for.sh
 │
 ├─ ① baseline train.py を実行
 │      ↓
 │    train.log
 │      ↓
 │    シェルが val_bpb を抽出
 │      ↓
 │    results.tsv に記録
 │
 ├─ ② Codex
 │      ├─ results.jsonl を読む
 │      ├─ 過去のログ・diffを見る
 │      └─ train.py だけ変更
 │
 ├─ ③ シェルが変更diffを保存
 │
 ├─ ④ train.py を実行
 │
 ├─ ⑤ シェルが結果を解析
 │
 ├─ 改善 → keep + git commit
 │
 └─ 悪化 → discard + train.py を元に戻す
        │
        └────────────→ 次のCodex
```

## プロンプト

原文(LLM作成)：

```text
You are preparing exactly one candidate experiment for an autonomous
LLM training loop on Genkai.

Current iteration: ${ITER}
Current accepted commit: ${BASE_COMMIT}

Primary metric:
val_bpb (lower is better)

The shell script owns:

- training execution
- results.jsonl
- keep/discard decisions
- git commits

Your task is ONLY to choose the next experiment and edit train.py.

Instructions:

- Read README.md, prepare.py, train.py, and results.jsonl.
- Inspect previous artifacts under results/ when useful.
- Choose one change that has a plausible chance to lower val_bpb.
- Prefer one-factor-at-a-time and small/local changes initially.
- Avoid repeating previous experiments.
- Edit ONLY train.py.
- Do NOT run uv run train.py.
- Do NOT edit prepare.py.
- Do NOT edit program.md.
- Do NOT edit results.jsonl.
- Do NOT edit scripts.
- Do NOT modify .git.
- Do NOT run git commit/reset/checkout/restore.
- Leave train.py runnable as-is.

Final response:
output only a short one-line description of the experiment.
```

和訳：

```text
あなたは、玄界（Genkai）上で動作する自律LLM学習ループのために、**次の候補実験を1つだけ**準備します。

現在のイテレーション: ${ITER}
現在採用されているコミット: ${BASE_COMMIT}

主要評価指標:
val_bpb（低いほど良い）

以下の処理はシェルスクリプト側が担当します。

* 学習の実行
* results.jsonl の管理
* keep / discard の判定
* Gitコミット

あなたのタスクは、**次に行う実験を1つ選び、train.py を編集することだけ**です。

指示:

* README.md、prepare.py、train.py、results.jsonl を読む。
* 必要に応じて results/ 以下にある過去の実験成果物も確認する。
* val_bpb を下げられる可能性が妥当にある変更を1つ選ぶ。
* 初期段階では、原則として一度に1要因だけ変更し、小さく局所的な変更を優先する。
* 過去に行った実験を繰り返さない。
* **train.py のみ編集する。**
* `uv run train.py` は実行しない。
* prepare.py は編集しない。
* program.md は編集しない。
* results.jsonl は編集しない。

* train.py は、そのまま実行可能な状態にしておく。
```
