### 研究リポジトリ内の、結果をプロットしたグラフ.png　の保存方法

現状の構成は以下の通りになっている。

```
.
├── 結果をプロットしたグラフ.png
└── results/      # .gitignore
    └── EXP_DIR/
        ├── baseline
        ├── round_0
        └── results.jsonl
```

しかし、

- 実験数が増えると管理が大変
- git に保存する場合、実験数が増えると圧迫する

という問題があるため構成を変更した。
変更後の構成は以下の通りになっている。合わせて `script/genkai/plot_results_parallel.sh` を変更。

```
.
└── results/      # .gitignore
    └── EXP_DIR/
        ├── baseline
        ├── round_0
        ├── 結果をプロットしたグラフ.png
        └── results.jsonl
```
