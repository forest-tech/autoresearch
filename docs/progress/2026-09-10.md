### ジョブを複数のブランチから投げたいときの対処法

`git worktree` を使うと、1つのGitリポジトリから複数ブランチを別ディレクトリで同時に扱える。

- 1 job = 1 worktree = 1 branch とすると、複数ジョブを安全に並列実行しやすい。

```
git worktree add ../autoresearch-exp-b -b autoresearch/exp-b HEAD
```

- HEAD を指定すると、現在いるブランチの現在のコミットを起点に新しいブランチを作成する。
- master を起点にしたい場合は、最後を master に変更する。

```
git worktree add ../autoresearch-exp-b -b autoresearch/exp-b master
```
