## NOTES

### シェルスクリプトの引数展開による構文エラーの修正

実行時に以下のエラーが発生した。

```text
--primary-metric: -c: line 1: unexpected EOF while looking for matching `''
--primary-metric: -c: line 2: syntax error: unexpected end of file
```

**原因：** `experiment_tool` 関数内の `$@` が複数の引数に展開され、`bash -lc` に渡すコマンド文字列が途中で分割された。その結果、シングルクォートが閉じず、Python実行前に構文エラーとなった。

**修正：** コマンド文字列と引数を分離し、内側の Bash で `"$@"` を展開するよう変更する。

```bash
# 修正前
bash -lc "uv run '${EXPERIMENT_TOOL}' '$@'"

# 修正後
bash -lc 'uv run "$@"' _ "${EXPERIMENT_TOOL}" "$@"
```

**確認：** Bash単体でエラーを再現し、修正後の形式で空白や引用符を含む引数も正しく渡せることを確認した。ジョブ全体の再実行確認は別途必要。
`$@` は `$1, $2, ...` のように展開されるため、`$0` は `_` に置き換えて無視する。
