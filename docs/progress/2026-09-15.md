## NOTES

### worker ごとに戦略(prompts)を変える実験のプログラムのテスト

| worker | 戦略                     | 狙い                           |
| ------ | ---------------------- | ---------------------------- |
| 0      | Default / conservative | 現行探索を対照群として固定                |
| 1      | Random coordinate      | 多数のパラメータから1つをランダム寄りに選んで局所変更  |
| 2      | Sparse mutation        | GAの突然変異のように、ほとんどを維持し1〜2個だけ変異 |
| 3      | Adaptive mutation      | 履歴を見て未探索・停滞している方向を優先的に変異     |
