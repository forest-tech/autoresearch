## NOTES

### `pjstat` などで表示される `JOB_NAME` について

#### 現状

デフォルトでは、投入したシェルスクリプトの名前がそのまま `JOB_NAME` となる。

```bash
❯ pjstat
JOB_ID     JOB_NAME   MD ST  USER     START_DATE      ELAPSE_LIM            NODE_REQUIRE    VNODE  CORE V_MEM    
6818145    parallel_l NM QUE ku500015 (09/17 02:00)<  0002:00:00            1               -      -    -
```

しかし、この設定では、現在の「内部の変数を変えた同一の名前のシェルスクリプトを複数投げる設定」と相性が悪く、どの設定のジョブを投げていて、どの設定が完了したのか `pjstat` しただけではわからない状態になっている。
これでは状況を追うのが面倒かつ、ミスの原因になる。

#### 解決方法

ジョブを投げるときに `pjsub -N` または `pjsub --name` とする。

```bash
❯ pjsub -N <JOB_NAME> <SHELL_SCRIPT>
❯ pjsub --name <JOB_NAME> <SHELL_SCRIPT>
```

毎回書くのは面倒なので、JOB_NAME, DATE などを書いた、ジョブを投げるようのシェルスクリプトを作り、それを動かすと簡単。
`scripts/genkai/submit.sh` を作成。

submitter で書いた変数を job に反映させるには

```bash
export JOB_NAME
```

とする。
